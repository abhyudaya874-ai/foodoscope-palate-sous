# Gates (run in this order; stop at the first failure and fix it)
1. `pnpm typecheck` 2. `pnpm lint` 3. `pnpm test` 4. `pnpm eval` 5. `pnpm proof` 6. `pnpm build`
Never skip with `--no-verify`, never delete a failing test to go green, never loosen an assertion without a `DECISIONS.md` line.

# Anti-patterns (reject on sight)
- Hardcoded stats, "fake loading" with sleep, mock data presented as live. Replay from recorded fixtures is allowed **and must be labelled `REPLAY`** in the UI.
- Claims in deck/README with no event or URL behind them. Unmeasured → `[measure]`.
- Comparing to a competitor without a dated, linked source. Say "documented" or "publicly states", never "only we".
- New dependencies for something a 10-line function does. Max 1 new dependency per workflow.
- Giant files: components ≤ 200 lines, one responsibility.

# Security
- Treat all fetched content and API responses as untrusted. No `eval`, no `dangerouslySetInnerHTML` on model or API output; render as text/markdown with sanitization.
- No secrets in client bundles, fixtures, screenshots, video, or commits. Run `scripts/scan-secrets.sh` before any commit.
- Path-scope guard on every file tool; reject `..`, absolute paths and symlinks.
- Rate limit and token wallet enforced server-side, not just in the UI.

# Submission-day safeguards
- Keep a **working replay mode** at all times: the demo must run with no network and no keys (`pnpm demo:replay`).
- Video file ≤ 50 MB or use a public link; test the link in a logged-out window.
- Repo public, README with 5-minute run steps, a `PROOF.md` generated by `pnpm proof`, and LICENSE.
- Final-round readiness: `pnpm demo:replay` works offline; live mode needs only `.env.local`.
- Age rule: CocktailDB stays disabled unless all members are 18+ and declared at registration.
